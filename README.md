# Compra Familiar v0.18.3 — Código experimental para lectura y estudio

**Edición v0.18.3-lectura-r1 · 24/11/2026**

Compra Familiar organiza listas, compras y tickets. Esta edición contiene 28 fuentes de JavaScript, HTML y configuración web. Los archivos se ofrecen como texto para facilitar su lectura y revisión. Para ejecutar o instalar la aplicación hacen falta recursos, configuración y dependencias adicionales.

Abre un archivo de la lista inferior. La vista del repositorio permite seleccionar texto o copiar el archivo. Consulta el [inventario](INVENTARIO_SHA256.json), el [historial](CAMBIOS.md) y la [versión](VERSION.json). Contrasta el SHA-256 del ZIP con el registro externo de la publicación.

Para proponer una mejora, indica versión, archivo y líneas, qué cambia y cómo se comprobó con datos ficticios. Comparte material propio o que tengas derecho a aportar. Toda integración y atribución requiere revisión y acuerdo posterior. Consulta las [instrucciones de colaboración](CONTRIBUTING.md).

Quedan fuera datos, credenciales, configuración de sincronización, bibliotecas empaquetadas, iconos y modelos. La [guía de estructura](RECONSTRUCCION.md) explica qué falta para preparar una copia reproducible. Consulta [créditos y derechos](CREDITOS.md) y [condiciones](SEGURIDAD.md). El código propio de esta edición se distribuye bajo [MIT](LICENSE). Las pruebas del original no validan esta edición de lectura como instalable.
