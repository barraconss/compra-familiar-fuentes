# Colaborar con Compra Familiar · YAG LAB

Esta edición experimental reúne fuentes de lectura de v0.18.3. Consulta el [inventario del README](README.md), el [mapa de reconstrucción](RECONSTRUCCION.md) y los [límites de seguridad](SEGURIDAD.md).

## Informar o proponer

Cuando se habiliten las incidencias, elige «Informar de un problema» o «Proponer una mejora». Indica la versión, el archivo de fuente, las líneas si las conoces y los pasos para revisar la propuesta con datos ficticios. Las incidencias y las solicitudes de cambios son públicas.

Comparte solo material propio o autorizado e indica la procedencia y licencia de cualquier fragmento adaptado. Omite credenciales, registros de hogares, datos personales, configuraciones reales y ZIP privados. Para una posible exposición de datos, usa el canal privado que indique el proyecto cuando esté disponible. Evita incluir detalles sensibles en una incidencia.

## Proponer un parche

Para presentar un parche sobre el código propio publicado bajo MIT, crea un fork, limita el cambio y abre una solicitud de cambios sobre la rama principal del repositorio de lectura. Explica el problema, las rutas cambiadas, la procedencia del código y las comprobaciones que realmente hiciste. Una propuesta en este repositorio no cambia la aplicación original.

## Revisión y aceptación

La persona mantenedora revisa alcance, procedencia, permisos, privacidad, efectos y verificaciones. Antes de integrar, se acuerdan licencia y atribución conforme a las condiciones vigentes. Las aportaciones se revisan como texto y no disparan ejecuciones automáticas. Solo las personas mantenedoras autorizadas pueden integrar cambios. Evita usar Google Forms para enviar parches de este repositorio.
